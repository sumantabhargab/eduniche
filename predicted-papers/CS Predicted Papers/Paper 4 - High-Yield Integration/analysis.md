### Common Mistakes
1. **Tree height definition** — Some books define height as nodes (root=1), others as edges (root=0). GATE typically uses edges-based.
2. **Complete graph edges** — Don't forget: edges = n(n-1)/2, not n².
3. **Relation properties** — Check ALL pairs for each property. Missing one pair means the property fails.
4. **Eigenfunction confusion** — Only e^(kx) is eigenfunction of d/dx. sin/cos are NOT.
