# PadhaiShuru Pitch Deck — Canva Prompts

Use these prompts in Canva's AI design tool. Each prompt is for one slide. Start with a blank presentation in 16:9 aspect ratio. Use the color palette and brand guidelines below for every slide.

---

## Brand Guidelines (Apply to All Slides)

- Background: Dark near-black (#0a0a0a or Canva's "Charcoal" / "Dark" preset)
- Primary accent: Electric blue (#3b82f6)
- Secondary accent: Teal (#14b8a6)
- Text: White for headings, light gray (#a1a1aa) for body, medium gray (#71717a) for labels
- Font: Inter (available in Canva) for everything. No serif fonts.
- Style: Minimal, clean, generous whitespace. Cards with subtle borders. Thin colored top bars on cards. No stock photos. Text and geometry only.
- Brand name: PadhaiShuru. No "EduNeuro" anywhere.
- Tagline: "Where students learn and teachers earn."
- No em dashes in any text. Use periods, commas, or line breaks.
- All rupee amounts in INR format.

## HOW TO USE THIS IN CANVA

1. Open Canva and create a new presentation in 16:9 aspect ratio.
2. For each slide, copy the prompt under that slide's heading.
3. Paste it into Canva's AI design tool (Magic Studio or the text-to-design feature).
4. Review the generated layout and adjust spacing, font sizes, and alignment to match the specifications.
5. Apply the brand colors and Inter font consistently across all slides.
6. If Canva's AI does not produce the exact layout, use the prompt as a specification and manually arrange the elements using Canva's editor.
7. After all 15 slides are done, review for consistency: same colors, same fonts, same card styles, no em dashes, no "EduNeuro" anywhere.
8. Export as PDF for the grant application upload (must be under 10MB).
