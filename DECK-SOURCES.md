# EduNeuro Pitch Deck — Source Documentation

## Deck Structure (12 Slides)

1. **Cover** — "THE AI STUDY COMPANION"
2. **Problem** — Tool fragmentation, students as their own OS
3. **Aha Moment** — The missing layer is student intelligence
4. **Product Architecture** — PLAN → LEARN → PRACTICE → FOCUS → MEASURE → ADAPT → Student Intelligence
5. **Actual Product** — Live screenshots (5 features + 1 coming soon)
6. **Traction** — Key metrics (505 visitors, 3,093 page views, ~400 peak daily, 250K+ organic reach)
7. **User Signal** — 100+ willingness-to-pay respondents
8. **Market** — Bottom-up TAM/SAM/SOM with calculations
9. **Competition** — Positioning vs Unacademy, ChatGPT, Notion, EduNeuro
10. **Go-to-Market** — GATE wedge → expansion exams → broader student market
11. **Roadmap** — Now → 6mo → 12mo → 18mo
12. **Closing** — "The system that understands how a student learns"

## Design Decisions

- **Color**: Near-black (#0a0a0a) base, electric blue (#3b82f6) accent
- **Typography**: Inter (sans-serif) throughout, no serif
- **Layout**: Full-bleed slides, generous whitespace
- **Navigation**: Keyboard arrows + touch + click
- **Animations**: Subtle pulse, hover states, progress bar
